# 연희단 결 (GYEOL : The Grain of Sound) — UI inspect 일련번호 태깅 및 원클릭 인스펙션 규격

본 문서는 의뢰자(기획자/클라이언트)와 AI 에이전트 간의 정밀한 UI 소통을 위해 **「연희단 결 (GYEOL : The Grain of Sound)」 공식 원페이지 웹(`https://neptune.axfoundly.com`, Port `3030`) 및 3대 액션 모달 전역에 적용되는 UI inspect 태깅 시스템**의 표준 규격을 정의한다.

---

## 1. UI inspect 일련번호 명명 체계 (Taxonomy)

화면 내 모든 주요 UI 요소는 고유한 일련번호(`data-serial-id`)를 부여받으며, 일관된 3단 계층 구조를 갖는다:

```text
[화면/섹션 코드] - [서브 영역 코드] - [요소 약어 + 순번]
예시: G01-HERO-TTL01, G05-ACT-BTN01, G00-STK-BTN01, M01-FRM-INP01
```

## 2. UI inspect 동작 및 시각 스타일 규격

### 2-1. 단축키 및 FAB 토글
- **전역 단축키**: **`Alt + I`** 또는 **`Ctrl + Shift + T`**
- **플로팅 버튼(FAB)**: 화면 우측 상단 또는 하단 고정 바 상단에 간섭 없이 배치
  - 기본 상태 라벨: `🏷️ UI inspect (Alt+I)`
  - 활성화 상태 라벨: `🏷️ UI inspect ON (Alt+I)`
  - URL 파라미터 지원: `?inspect=1` 진입 시 초기 로딩부터 자동 활성화

### 2-2. 원클릭 클립보드 4대 필수 정보 복사
일련번호 뱃지를 클릭하면 클립보드에 아래 4대 필수 정보가 자동 복사된다:
```text
- 일련번호: G05-ACT-BTN01
- 페이지명: 연희단 결 (GYEOL : The Grain of Sound)
- URI: https://neptune.axfoundly.com/
- 항목명: [공연 신청하기] 모달 호출 액션 버튼
```
동시에 하단 중앙에 토스트 알림이 표시된다:
`📋 [G05-ACT-BTN01] 4대 정보 복사 완료! (일련번호/페이지/URI/항목명)`
